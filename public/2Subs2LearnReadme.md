# 2Subs2Learn

An advanced, cross-browser extension designed for language learners on YouTube and ZDF. Powered by client-side neural machine translation via Hugging Face Transformers.js and ONNX Runtime Web.

This project is built to enable language learners to follow entertainment video with simultaneous original and translated subtitles. It features dual subtitle overlays on YouTube & ZDF, with real-time customizable font sizing, offsets, and positioning.
